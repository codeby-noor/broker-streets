# Broker Streets

Gujarat's trusted agricultural & non-agricultural land marketplace.

## Repository Structure

```
broker-streets/
├── frontend/     — React/Vite SPA (buyer/seller portal + admin panel)
├── backend/      — Node.js/Express API (Phase 1+)
├── BACKEND_SPEC.md — Living backend specification
├── .gitignore
├── README.md
└── package.json  — Root workspace scripts
```

## Quick Start

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend dev server starts at `http://127.0.0.1:4173`.

### Backend

Backend implementation will follow the specification in `BACKEND_SPEC.md`.

## Architecture

- **Frontend:** React 18, Vite 8, Tailwind CSS 3, Zustand, React Router 6
- **Backend:** Node.js, Express, MongoDB (planned — see BACKEND_SPEC.md)
